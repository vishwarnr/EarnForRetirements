# EarnForRetirements

This is an [Expo](https://expo.dev) application.

## Get started

1. Install dependencies:

   ```bash
   npm install
   ```

2. Start the app:

   ```bash
   npx expo start
   ```

The Expo CLI output includes options to open the app in a development build, Android emulator, iOS simulator, or Expo Go.

The app uses file-based routing. Start developing by editing files in the `app` directory.
